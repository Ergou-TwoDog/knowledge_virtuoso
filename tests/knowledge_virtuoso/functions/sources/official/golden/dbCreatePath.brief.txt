函数: dbCreatePath
签名: dbCreatePath(
d_cellView txl_layerPurposel_points
n_width
[ t_pathStyle ]
)
=> d_path / nil
描述: Creates a path.
Note: dbCreatePath is a core database SKILL function that checks only for even multiples of database units to create a path. As a result, the created path can be off grid. To create a path with required constraints and additional level of automation use an end-application SKILL function, such as leCreatePath.
来源: skdfref/chap2.html

参数:
  d_cellView — The cellview.
  txl_layerPurpose — Name, number, or a list of layer or layer-purpose pair.
    For more information, see Type txl_layerPurpose.
  t_purpose — Purpose, if not specified, defaults to drawing.
  l_points — Point list; must contain at least two points.
    For more information, see Type l_point.
  n_width — Path width specified in user units.
  t_pathStyle — Path style, defaults to truncateExtend.
    For more information, see Type t_pathStyle.

返回:
  d_path — The dbObject of the path.
  nil — The path is not created.
