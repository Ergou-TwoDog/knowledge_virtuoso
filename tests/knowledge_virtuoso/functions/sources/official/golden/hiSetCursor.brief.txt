函数: hiSetCursor
签名: hiSetCursor(
w_windowIdx_cursor
)=> t / nil
描述: Sets the cursor you specify for the window.
来源: skuiref/chap9.html

参数:
  w_windowId — The window ID.
  x_cursor — The integer ID associated with the cursor you want to set. The following table lists the constants that are legal values for this argument, as well as their equivalent X Windows cursors:
