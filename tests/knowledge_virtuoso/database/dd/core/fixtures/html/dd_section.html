Attributes of Data Management Objects

The attributes of data management objects use the following operators to access data management objects with SKILL:

(~>)

To access any attribute or property of an object

(~>?)

To see names of all attributes of an object

(~>??)

To see names and values of all attributes and properties of an object

If you ask for an attribute that is not applicable for the database object or for a property that does not exist on the object, the system returns nil.

In these figures, types of data returned by an attribute are shown as

b

a DDPI object

d

an identifier

f

a floating point number

g

any of the data types

l

a list

n

a number, either integer or floating point

s

a symbol

t

a character string

x

an integer
